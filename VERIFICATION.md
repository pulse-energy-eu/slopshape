# Verification guide: every paper number to its artifact

For each exhibit of the paper "SlopShape: Identifying AI-Generated
Commercial Web Content", this file names the included file that carries the
number and the repository script that regenerates it.
artifacts/METHODOLOGY.md is the canonical prose record; every value below
also appears there with its context.

Conventions: the paper reports macro-F1 in percent (98.0); artifacts store
four-decimal proportions (0.9803). The paper presents eight numbered
robustness checks (its Table 8 / Appendix G) plus prose exhibits; artifacts
and METHODOLOGY keep the repository battery numbering (8.1-8.21) - the
mapping is given in the robustness table below. One granularity note:
parity_fixes.json p2_core_fingerprint.core records the parity batch's
FEATURE-granularity core pass, which selected nothing; the paper's core is
the faithful VALUE-granularity selection (the original's unit) in
core_values_selection.json (METHODOLOGY.md section 7). The six-way and
fingerprint blocks of p2_core_fingerprint are the paper's Table 5 / F3
sources.
